# Mini-Banco-Lucas-
Projeto de um sistema sobre Mini Banco, para realizarmos saques, depositos.

As funcionalidades deste sistema, são 
1 - Depositar 
2 - Sacar
3 - Ver o saldo atual
4 - Ver o Extrato do nosso sistema.

A linguagem utilizada foi o Java, com seus conceitos, Variáveis e conceitos primitivos, Entrada de dados com scanner, métodos void, condicionais (if , else , else if ) , Booleanos e validações, e interações com for , while e do while.
Utilizamos o Visual Studio Code para realizarmos a programação deste sistema.
